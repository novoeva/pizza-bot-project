Q4 · Copy pass, no app needed
Read the 12 check-line sets below. Any line you would change?
Token · chunks not words, one word can be several tokens · more tokens = slower and pricier · it never sees letters, so counting letters goes wrong · Don't ask it to count letters and trust it.
Context window · only the last few messages, oldest fall out · not careless, just out of view · pin it, repeat it, or start fresh · Don't assume 20 messages ago is still in view.
Hallucination · made-up sounds as confident as true · confidence is not evidence · give it real data and guessing drops · Don't trust an unverifiable detail because it sounds sure.
Prompt · everything you leave out, it guesses · say what to do when info is missing · wording changes the bot, not the customer · Don't blame the customer for a vague order when instructions were vague.
Agent · chatbot talks, agent acts · steps in order, order matters · more power, more guardrails · Don't let an agent act without limits.
Tool use · memory is a guess, a real system is a check · give it tools · the right tool, not any tool · Don't let it answer a live question without a tool.
Skill · a playbook for one recurring situation · same complaint, same right answer · steps in the order you'd handle it · Don't let it improvise the situations that matter most.
Memory · working memory lasts one chat · persistent memory comes back next visit · you choose what is saved · Don't expect it to remember last week unless something was saved.
MCP · one shared plug · no custom bridge per pair · strangers' tools click in on day one · Don't build a connector when the tool speaks MCP.
Guardrails · hard limits: money, promises, topics · above the limit a human decides · test with a pushy customer's tricks · Don't trust "I'm the manager".
Temperature · same words, only the odds change · low = safe word, high = surprises · down for exact wording, up for ideas · Don't leave it high for anything that must read the same.
RAG · it looks documents up per question · only sees the pages the search found · can't tell current from outdated, ask which page · Don't assume "from our documents" means the right document.
