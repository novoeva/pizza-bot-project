3 · The 12 "In other words" lines

TokenThe bot never sees whole words. It sees small chunks called tokens, and every chunk it reads or writes takes time and costs money.
Context windowThe context window is the bot's short-term memory: the part of the conversation it can still see. When it is full, the oldest lines drop out.
HallucinationA hallucination is a confident answer that happens to be false. The bot doesn't know it is guessing, so it sounds just as sure as when it is right.
PromptThe prompt is the set of instructions your bot works from. Whatever the instructions don't cover, the bot fills in with a guess.
AgentAn agent is a bot that doesn't just answer, it acts: it takes real steps in real systems, one after another, to get the job done.
Tool useTool use means the bot checks a real source, like the menu or the delivery tracker, instead of answering from what it remembers.
SkillA skill is a fixed routine you write once for a situation that keeps coming back, so the bot handles it the same right way every time.
MemoryWorking memory is what the bot keeps during one chat. Persistent memory is what you save on purpose so it is still there next time.
MCPMCP is a shared standard, one universal port, so any tool that speaks it can plug into your bot without a custom connector.
GuardrailsGuardrails are the limits you set in advance: the discounts, promises and topics the bot may never go past, no matter how a customer pushes.
TemperatureTemperature is the dial for how adventurous the bot's wording is: low picks the safe word almost every time, high lets surprising words win.
RAGRAG means the bot looks things up in your documents for each question and answers only from the pages it found, without knowing whether they are current.
