Pizza Bot · Phase 1 · shared components

How to review Phase 1 in 15 minutes

Phase 0 approved. Phase 1 builds the first four shared pieces and swaps them into all 12 games: Callout (the verdict card), ChatMessage (the speech bubble), PhaseCard (the "Game · …" card) and Panel (reference boxes like the menu and the context window). No game logic changed, no text changed except three progress labels.

1 · What changed

  1. One verdict card. Every "correct" / "problem" / "Real talk" box in every game is now the same shape. Before there were four shapes.
  2. One speech bubble. Every message uses the same bubble and avatar. Customer on the left, your bot on the right, in all 12 games. Memory used to have it backwards.
  3. Prompt results fixed (FR-11). A wrong choice on the round 3 results screen is now a muted red card, and the better option is plain advice with an arrow, not green text.
  4. Reference boxes share one frame. "Today's real menu" (red header), "Context window" (navy header), the dial, the ranking, the to-do list.
  5. MCP's cost counters are red, not amber, because a cost that hurts is a "problem" (decision R3).
